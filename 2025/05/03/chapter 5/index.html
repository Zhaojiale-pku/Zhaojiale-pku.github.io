5.1 二叉树及其抽象数据类型
定义：结点的有限集合，或为空（此时称为空二叉树），或由一个称为根的节点和两棵不相交的左子树和右子树（均为二叉树）组成。

相关概念一览：
父节点、左（右）子节点、边
兄弟
祖先、子孙
路径、路径长度
结点的层数（注意根的层数为0）
结点的度数，二叉树中最大为2
二叉树的高度，只有一个结点的二叉树层数为0
树叶、分支节点

特殊的二叉树
满二叉树：任何结点，要么是树叶，要么有两棵非空子树。
完全二叉树：只有最下面的两层结点度数小于2，其余都等于2。并且最后一层的结点都集中在最左端。
扩充二叉树：外部结点（树叶结点），内部结点。外部路径长度E，内部路径长度I

Huffman树及其应用
这个我之前研究了蛮久，算是比较清楚其原理

struct HtNode{
    int ww;
    int parent,llink,rlink;
};
struct HtTree{
    int m;
    int root;
    struct HtNode*ht;
};
typedef struct HtTree*PHtTree;

//Huffman算法
PHtTree huffman(int m,int*w){
    PHtTree pht;
    int i,j,x1,x2,m1,m2;
    pht=(PHtTree)malloc(sizeof(struct HtTree));
    if(pht==NULL){
        printf("Out of space!!\n");
        return pht;
    }
    pht->ht=(struct HtNode)malloc(sizeof(struct HtNode)*(2*m-1));

    for (i = 0; i < 2 * m - 1; i++) {
    pht->ht[i].ww = (i < m) ? w[i] : 0;
    pht->ht[i].parent = -1;
    pht->ht[i].llink = -1;
    pht->ht[i].rlink = -1;
    }
    
    if(pht->ht==NULL){
        printf("Out of space!!\n");
        return pht;
    }
    for(int i=0;i<m-1;i++){
        m1=MAXINT;m2=MAXINT;
        x1=-1;
        x2=-1;
        for(int j=0;j<m+i;j++){
            if(pht->ht[j].ww<m1&&pht->ht[j].parent==-1){
                m2=m1;
                x2=x1;
                m1=pht->ht[j].ww;
                x1=j;
            }
            else if(pht->ht[j].ww<m2&&pht->ht[j].parent==-1){
                m2=pht->ht[j].ww;
                x2=j;
            }
        }
        pht->ht[x1].parent=m+i;
        pht->ht[x2].parent=m+i;
        pht->ht[m+i].ww=m1+m2;
        pht->ht[m+i].llink=x1;
        pht->ht[m+i].rlink=x2;
    }
    pht->root=2*m-2;
    return pht;
}
