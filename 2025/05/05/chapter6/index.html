在ppt中，老师使用了一个memset函数，下面是其解释：
memset 是 C 语言标准库中的一个函数，用于将一块内存中的所有字节设置为某个固定的值。它在 <string.h> 头文件中声明。
void *memset(void *ptr, int value, size_t num);
ptr：指向要设置的内存起始地址。
value：要设置的值（注意：是一个 字节值（0~255），会自动转成 unsigned char）。
num：要设置的字节数。
