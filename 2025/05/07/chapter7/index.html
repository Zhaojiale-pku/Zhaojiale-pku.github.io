if（p无左子女）

else{

用r的右指针指向p的右子女；

}

else{

用r结点代替被删除的结点p；

}

7.5 平衡二叉排序树
7.5.1 基本概念
平衡二叉排序树，又称AVL树
平衡二叉排序树中每个结点的左右子树高度之差绝对值不超过1.结点右子树高度与左子树高度之差称为该结点的平衡因子，平衡二叉排序树中每个结点的平衡因子只能是1，0，-1.

最小不平衡树：指离插入结点最近，且以平衡因子绝对值大于1的结点为根的子树。
