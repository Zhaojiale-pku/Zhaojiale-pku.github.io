一、time函数

#include<time.h>
函数原型:
time_t time(time_t *t);
功能:
返回当前的日历时间（即从 1970 年 1 月 1 日 00:00:00 UTC 到现在的秒数，通常称为 Unix 时间戳）。
参数:
t：可以为 NULL，也可以是 time_t 类型变量的地址。如果不为 NULL，函数会把时间戳也写入该地址。
返回值:

二、srand函数
头文件：
#include <stdlib.h>
函数原型：
void srand(unsigned int seed);

功能
设定随机数生成器的“种子”，让 rand() 生成不同的随机数序列。通常使用 srand(time(NULL)) 来让每次程序运行产生不同的随机数。

参数
seed：一个整数值，用作随机数生成器的种子。相同的种子会产生相同的随机序列。

printf数字不要加&啊啊啊啊

你在读取字符操作符（op）时用了：
scanf(“%c”, &op);
这行可能会读取到前一个输入后的换行符或空格，导致 op 根本不是你想要的 ‘C’ 或 ‘Q’，而是 ‘\n’ 或 ‘ ‘。
✅解决方法：
在 %c 前加一个空格，跳过空白字符：
scanf(“ %c”, &op); // 加了空格！
