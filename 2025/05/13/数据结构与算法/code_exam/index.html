printf数字不要加&啊啊啊啊

你在读取字符操作符（op）时用了：
scanf(“%c”, &op);
这行可能会读取到前一个输入后的换行符或空格，导致 op 根本不是你想要的 ‘C’ 或 ‘Q’，而是 ‘\n’ 或 ‘ ‘。
✅解决方法：
在 %c 前加一个空格，跳过空白字符：
scanf(“ %c”, &op); // 加了空格！

strcspn 是 C 标准库 <string.h> 中的一个函数，全称是 “string complement span”。

✅ 函数原型
c
复制
编辑
size_t strcspn(const char *str1, const char *str2);
✅ 功能说明
strcspn(str1, str2) 会返回从 str1 开头起第一个出现在 str2 中的字符的位置（索引）。

如果 str1 中没有任何字符出现在 str2 中，就返回 strlen(str1)。

✅ 常见用途：去掉换行符 \n
c
复制
编辑
fgets(line, 205, stdin); // 读取一行字符串，可能含换行符
line[strcspn(line, “\n”)] = ‘\0’; // 把换行符替换成结束符
这是 去除 fgets 读取字符串中的换行符 的标准写法。

🧠 举个例子：
c
复制
编辑
#include <stdio.h>
#include <string.h>

int main() {
char s[] = “hello, world\n”;
size_t pos = strcspn(s, “\n”);
printf(“位置：%zu\n”, pos); // 输出位置
s[pos] = ‘\0’; // 去掉换行符
printf(“结果：%s\n”, s); // 输出处理后的字符串
return 0;
}
输出：
复制
编辑
位置：12
结果：hello, world
🟡 你可以理解为：
strcspn(str, “\n”) 是返回字符串中 ‘\n’ 的下标位置。

  6. 🧠 strtok() 函数详解
    📌 作用：
    将一个字符串按照某个分隔符拆分成一系列“单词”（更准确地说，是“子字符串”）。

✅ 函数原型：
c
复制代码
char *strtok(char *str, const char *delim);
参数解释：
str：要被分割的字符串。第一次调用时传原字符串；之后调用要传 NULL，表示继续分割上一次的字符串。

delim：分隔符组成的字符串（比如 “ “ 表示用空格分割）。

返回值：
返回指向每个被分割出的“单词”的指针。

如果没有更多“单词”了，返回 NULL。

✅ 示例说明：
c
复制代码
char line[] = “one million one hundred one”;
char *token = strtok(line, “ “);
第一次调用后：

token 指向 “one”

然后我们继续用 strtok(NULL, “ “) 得到下一个单词：

c
复制代码
token = strtok(NULL, “ “); // 第二次：返回 “million”
token = strtok(NULL, “ “); // 第三次：返回 “one”
…
循环使用：

c
复制代码
char *token = strtok(line, “ “);
while (token != NULL) {
// 对每个 token 处理
printf(“token = %s\n”, token);
token = strtok(NULL, “ “); // 获取下一个单词
}
✅ 为什么能工作？
strtok() 内部使用了一个静态指针，记住了当前处理到哪里，因此只需要在第一次传入原始字符串，后面传 NULL 它就能继续上次的地方。

⚠️ 注意事项
strtok 会修改原字符串，它会把分隔符（比如空格）改成 \0。

所以 line 被分割后，不再是完整的字符串了。

不是线程安全。如果你想在多线程中使用，建议用 strtok_r()。

🧪 举个例子：
c
复制代码
char str[] = “hello world from C”;
char *token = strtok(str, “ “);

while (token) {
printf(“token: %s\n”, token);
token = strtok(NULL, “ “);
}
输出：

vbnet
复制代码
token: hello
token: world
token: from
token: C

#include <stdio.h>
#include <string.h>

int main() {
char str[] = “one million one hundred one”;
char *token;

// 第一次调用 strtok：传入原始字符串
token = strtok(str, " ");

// 循环：每次调用 strtok(NULL, " ") 继续分割
while (token != NULL) {
    printf("token: %s\n", token);
    token = strtok(NULL, " ");
}

return 0;

}
